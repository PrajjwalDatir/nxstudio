## 2025-02-14 - Open Redirect Bypass via Protocol-Relative URL Normalization
**Vulnerability:** The open redirect guard in the application correctly blocked absolute URLs (`//attacker.com`) to prevent attackers from hijacking the `redirectTo` query parameter. However, it failed to account for browser URL normalization, where a path starting with `/\` (e.g., `/\attacker.com`) is automatically normalized into the protocol-relative URL `//attacker.com`.
**Learning:** Checking for `//` is insufficient for preventing open redirects. Browsers proactively "fix" URLs that contain mixed slashes (like `/\`), transforming them into valid protocol-relative links that bypass naive string-matching guards.
**Prevention:** Always explicitly check and reject paths starting with `/\` (e.g., `!path.startsWith("/\\")`) in addition to checking for `//` when authorizing dynamic redirect paths.
