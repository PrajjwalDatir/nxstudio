## 2024-03-24 - [CRITICAL] Supabase Auth Bypass via user_metadata
**Vulnerability:** Authorization checks were trusting `user.user_metadata?.role === "admin"` to grant administrative access.
**Learning:** In Supabase, `user_metadata` is editable by the user via the client-side Auth API. Trusting it for authorization allows any user to elevate their privileges to admin by simply updating their own metadata.
**Prevention:** For security authorization checks, always rely on `app_metadata` (which is only editable via the Admin API/server-side) or a secure database table (like `user_roles`). Never trust `user_metadata` for security/authorization.
